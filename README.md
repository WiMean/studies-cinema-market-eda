# Исследование рынка российского кинопроката

**Задача.** Заказчик — Министерство культуры РФ. Изучить рынок российского кинопроката, выявить текущие тренды и оценить, насколько интересны зрителю фильмы, получившие государственную поддержку.

**Что сделано.** Предобработка и очистка данных о прокатных удостоверениях, сборах и государственной поддержке; исследовательский анализ; анализ динамики сборов и окупаемости; сравнение фильмов с господдержкой и без неё; выводы и рекомендации заказчику.

**Стек.** Python, pandas, NumPy, Matplotlib, Seaborn, SciPy
